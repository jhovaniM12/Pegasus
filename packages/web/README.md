# Web de Pegasus

Interfaz Next.js del monorepo. Consulta el [README principal](../../README.md) para iniciar el proyecto y la [arquitectura](../../docs/02-arquitectura.md) para entender su relación con la API y `core`.

Desde la raíz, `pnpm dev:web` inicia la web y `pnpm dev:all` inicia web y API. Las rutas están en `src/app`, los componentes en `src/components`, los hooks en `src/hooks` y las llamadas HTTP en `src/services`.
